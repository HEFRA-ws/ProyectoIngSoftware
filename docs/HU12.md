# HU12: Gestionar usuarios y roles

**Historia:** Como Administrador, quiero crear, editar y desactivar cuentas, para controlar el acceso.

**Prioridad:** Alta.

**Estado en v0.2:** Pendiente.

## Criterios de aceptación

1. Crear y editar usuarios con correo único y rol permitido.
2. Activar o desactivar cuentas y controlar sus sesiones.
3. Restringir estas operaciones al administrador.
4. Registrar responsable y fecha en auditoría.

# HU01: Iniciar sesión

**Historia:** Como Usuario, quiero acceder con Google o con el correo y contraseña de mi cuenta existente, para utilizar las funciones de mi rol.

**Prioridad:** Alta.

**Estado en v1.0:** Implementada, incluido el registro e inicio con Google; pruebas de carga pendientes.

## Criterios de aceptación

1. Validar credenciales sin exponer contraseñas ni confirmar si existe el correo.
2. Crear sesión protegida y permitir cerrarla.
3. Aplicar permisos en el servidor para Trabajador, Profesional SST, Coordinador y Administrador.
4. Google crea una cuenta Trabajador en el primer acceso y utiliza la misma identidad en los siguientes. No permite elegir un rol privilegiado ni vincula cuentas locales por correo de manera automática.
5. Mantener el acceso con contraseña de las cuentas existentes. El registro público con contraseña queda fuera de esta historia implementada.

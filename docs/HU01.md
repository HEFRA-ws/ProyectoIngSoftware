# HU01: Iniciar sesión

**Historia:** Como Usuario, quiero acceder con correo y contraseña, para utilizar las funciones de mi rol.

**Prioridad:** Alta.

**Estado en v0.2:** Implementada; rendimiento pendiente.

## Criterios de aceptación

1. Validar credenciales sin exponer contraseñas ni confirmar si existe el correo.
2. Crear sesión protegida y permitir cerrarla.
3. Aplicar permisos en el servidor para Trabajador, Profesional SST, Coordinador y Administrador.

# Vigía SST

Aplicación web académica para registrar accidentes e incidentes laborales, verificar los eventos y elaborar un informe interno independiente del accidente.

## Problema y usuarios

Centralizar la declaración inicial, la evidencia y la investigación para facilitar el seguimiento. Solo el trabajador registra eventos y aporta evidencia a sus casos abiertos. SST verifica e investiga y elabora informes de accidentes. Coordinador y administrador consultan los eventos. SST y administrador responden quejas. La gestión de cuentas está pendiente.

## Estado

Versión 1.0: evento e informe separados, verificación SST, acciones correctivas con seguimiento y cierre condicionado. El informe es una propuesta interna del proyecto, no FURAT ni envío a ARL. Los incidentes mantienen investigación. Para cerrar un accidente se exige informe Emitido y acciones completas con evidencia. No se admiten nuevos adjuntos después del cierre.

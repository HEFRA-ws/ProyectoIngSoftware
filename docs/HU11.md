# HU11: Exportar un informe

**Historia:** Como Profesional SST, quiero exportar el documento del caso, para compartir una versión legible.

**Prioridad:** Media.

**Estado en v0.2:** Pendiente.

## Criterios de aceptación

1. Seleccionar evento o periodo según el alcance acordado.
2. Distinguir el informe interno de accidente del documento de investigación.
3. Generar PDF con identificación del evento, autor y fecha de emisión.
4. Autorizar la exportación y conservar legibilidad.

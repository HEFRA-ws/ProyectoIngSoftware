# HU14: Radicar y responder quejas y reclamos

**Historia:** Como usuario de la plataforma, quiero radicar una queja o un reclamo sobre la gestión de un caso o el funcionamiento del sistema, para recibir una respuesta trazable dentro de un plazo definido.

**Prioridad:** Media.

**Estado en v0.2:** Implementada.

## Criterios de aceptación

1. Cualquier usuario autenticado puede radicar una queja o un reclamo con asunto y descripción.
2. Distinguir el tipo: queja (inconformidad con la atención o el trato) o reclamo (solicitud de corregir algo que no funcionó como se esperaba).
3. Permitir vincular opcionalmente un evento al que el usuario tenga acceso; rechazar eventos inexistentes o ajenos.
4. Asignar un código único con prefijo QR, estado Radicada y una fecha límite de respuesta de 15 días hábiles, sin contar sábados ni domingos.
5. Mostrar a cada usuario solo sus quejas y reclamos; el Profesional SST y el Administrador consultan todos.
6. Solo el Profesional SST o el Administrador responden; la respuesta registra texto, responsable y fecha, y cambia el estado a Respondida.
7. Rechazar una segunda respuesta (409) y las respuestas de roles no autorizados (403).
8. Señalar en pantalla las quejas pendientes cuya fecha límite ya pasó.

## Decisiones del equipo

El plazo de 15 días hábiles es una referencia interna del prototipo; no incluye festivos ni acredita cumplimiento normativo. Las peticiones y sugerencias quedan fuera de esta versión.

## API

| Método | Ruta | Uso |
| --- | --- | --- |
| GET | /api/complaints | Consultar las quejas y reclamos visibles para el rol |
| POST | /api/complaints | Radicar una queja o un reclamo |
| PATCH | /api/complaints/:id | Registrar la respuesta (SST o Administrador) |
